# Всемирный день науки — лендинг Universal University

Промо-страница акции 10–12 ноября 2026: скидки до 50 000 ₽ по промокоду **НАУКА** на программы школ Universal University: Британская высшая школа дизайна, Московская школа кино, Московская школа музыки, Scream School, МАРШ, Московская школа современного искусства.

Один файл `index.html`, без сборки и зависимостей (шрифты Inter и Unbounded грузятся с Google Fonts).

## Перед запуском

- **Заявки:** подключить отправку в функции `sendLead()` (CRM / Bitrix24 / amoCRM / Telegram-бот). Сейчас данные только пишутся в консоль.
- **Метрика:** указать номер счётчика в `YM_ID` и вставить код Яндекс.Метрики. Цели уже размечены (`data-goal`, `lead_sent`, `quiz_done`, `calc_used`, `scroll_25…100` и др.).
- **Мессенджеры:** заменить `USERNAME` в ссылках Telegram и MAX.
- **Отзывы:** заменить заглушки в красной пунктирной рамке (класс `ph`) на реальные отзывы выпускников.
- **Даты акции:** константы `START` и `END` в начале скрипта (время московское).
- **Шкала скидок в калькуляторе** демонстрационная — сверить с условиями акции (массив `tiers`).

## Конверсионные элементы

Таймер обратного отсчёта (до старта / до конца акции), форма брони скидки на первом экране, квиз из 3 вопросов, калькулятор выгоды, карта направлений с CTA, копирование промокода, напоминание в Google Календарь, FAQ с отработкой возражений, exit-intent попап, обратный звонок, липкая CTA-панель на мобильных, маска телефона, сбор UTM-меток в заявку.
