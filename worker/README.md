# Заявки с лендинга → Telegram

Все 4 формы страницы (первый экран, тест, финальная форма, всплывающее окно) отправляют заявку на Cloudflare Worker. Он хранит токен бота в секрете и пересылает заявку в Telegram.

Токен бота **нельзя** вписывать в `index.html`: страница и репозиторий публичные, и любой сможет управлять ботом.

## 1. Узнать id чата для заявок

1. Создайте группу в Telegram (например, «Заявки — День науки»), добавьте туда бота и нужных менеджеров.
2. Напишите в группе любое сообщение, например `/start`.
3. Откройте в браузере (подставьте свой токен):
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates`
4. Найдите `"chat":{"id":…` — это и есть **TG_CHAT_ID** (для групп число отрицательное: `-5…` у обычной группы, `-100…` у супергруппы).

Если ответ пустой — отправьте в группу ещё одно сообщение и обновите страницу.

## 2. Создать Worker (5 минут, бесплатно)

1. Зайдите на [dash.cloudflare.com](https://dash.cloudflare.com) → **Workers & Pages** → **Create** → **Create Worker**.
2. Назовите, например, `uu-leads` → **Deploy**.
3. **Edit code** → удалите шаблон, вставьте содержимое `telegram-lead.js` → **Deploy**.
4. **Settings → Variables and Secrets → Add**:
   | Имя | Тип | Значение |
   |---|---|---|
   | `TG_TOKEN` | Secret | токен бота |
   | `TG_CHAT_ID` | Secret | id чата из шага 1 |
   | `ALLOWED_ORIGINS` | Text | `https://rdana743.github.io` (через запятую можно добавить боевой домен) |
5. Скопируйте адрес Worker'а вида `https://uu-leads.<ваш-аккаунт>.workers.dev`.

## 3. Подключить к странице

В `index.html` найдите строку и вставьте адрес:

```js
const LEAD_ENDPOINT = 'https://uu-leads.<ваш-аккаунт>.workers.dev';
```

## Что приходит в Telegram

Направление — прямо в заголовке сообщения («Заявка: Дизайн»), затем имя, телефон, ответы теста (если заявка из теста), в какой форме оставлена заявка, UTM-метки и адрес страницы. Если в форме нет поля направления (финальная форма, всплывающее окно), подставляется последнее направление, которое человек выбрал на странице: в сетке направлений, в тесте или в первой форме.

## Защита

- запросы принимаются только с доменов из `ALLOWED_ORIGINS`;
- скрытое поле-ловушка отсекает спам-ботов;
- если Telegram недоступен, страница повторяет отправку, а при повторной ошибке просит посетителя позвонить — заявка не «исчезает молча».
